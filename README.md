# REST Countries API with Color Theme Switcher

A web application that allows users to browse and search for countries around the world using the [REST Countries API](https://restcountries.com/).  
The app includes a dark/light theme toggle and detailed country view.

> This project is a solution to the [REST Countries API with color theme switcher challenge](https://www.frontendmentor.io/challenges/rest-countries-api-with-color-theme-switcher-8f7b8a6e) on Frontend Mentor.

## 🔧 Tech Stack

- **React** with **TypeScript**
- **React Router DOM** for routing
- **MUI (Material UI)** for base UI components
- **Tailwind CSS** for utility-first styling
- **SCSS** for modular styles
- **Vite** for fast development and build

---

## ✨ Features

- 🌐 Browse all countries with flag, name, population, region, and capital
- 🔍 Search countries by name
- 🌍 Filter by region
- 🧭 View detailed country info including border countries
- 🌗 Toggle between dark and light mode (theme switcher)
- 📱 Fully responsive layout
